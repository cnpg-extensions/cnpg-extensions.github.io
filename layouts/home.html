Set up alerts

Set up email alerts, or your preferred notification, on this PromQL query.

Alerts remind you to run ALTER EXTENSION … UPDATE when needed.

max by (namespace, cluster, datname, extname) (
  cnpg_pg_extensions_update_available
) == 1
PromQL
02

Install the catalog

with automatic updates

Once alerts are working, install the CNPG Extensions catalog with automatic updates at the start of your maintenance window.

Databases and extensions will be automatically updated to latest patch levels during the maintenance window. This is usually less than a minute of downtime for the restart, though it can take longer on large busy databases.

You can opt out from automatic updates by pinning image digests in your individual Cluster resources.

kind: CronJob
spec:
  schedule: "0 22 * * 2"
  timeZone: America/Los_Angeles
  jobTemplate:
    # … container configuration omitted
              command: [kubectl, apply, -f, https://raw.githubusercontent.com/cnpg-extensions/artifacts/main/image-catalogs-extensions/catalog-minimal-trixie.yaml]

Every Tuesday at 10 PM Pacific. Shortened example.
